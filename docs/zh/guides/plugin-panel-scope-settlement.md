# 插件面板的工作空间回执归属

插件列表、主题和输出风格目录属于发起读取时的工作空间及其数据代次。切换工作空间、重建同一工作空间或离开后再次进入时，面板重新读取目标，旧访问迟到的列表、错误和加载结束不覆盖本次访问。

主题激活、输出风格切换、安装、卸载、启停、配置、重新加载、脚手架和验证继续使用既有后端入口。操作在原目标开始后仍由原 owner 结算；页面切换只停止把旧访问的回执用于当前列表、提示、草稿或全局主题，不把它描述为后端取消。回到来源工作空间后可重新读取其实际状态。

同一次访问发生多次目录刷新时，只采用最新一次完整目录读取。列表、主题和输出风格仍按原组合读取方式更新，不从部分结果拼出成功状态。真实退役诊断与合法插件组件的验证结果继续同时显示。

本次修改只修复扩展面板的异步显示归属，不改变任务绑定的插件版本、内容摘要、激活和 retire 规则；foreground、Subagent、verification 与 resume 仍消费已有 TaskRun 绑定。不新增插件管理器、执行器、权限门控或存储。
