## 图表选择决策树

### 按数据维度选择

| 数据维度 | 目的 | 推荐图表 | 避免 |
|---------|------|---------|------|
| 1D 连续 | 分布 | 直方图、箱线图 | 饼图 |
| 1D 分类 | 频率 | 柱状图 | 饼图 (>5 类) |
| 2D 连续×连续 | 关系 | 散点图、热力图 | 饼图 |
| 2D 连续×分类 | 比较 | 箱线图、小提琴图 | 折线图 |
| 2D 连续×时间 | 趋势 | 折线图、面积图 | 饼图 |
| 2D 分类×分类 | 关联 | 堆叠柱状图、马赛克图 | 散点图 |
| 3D+ | 多变量 | 气泡图、平行坐标、雷达图 | 3D 图表 |

### 常见误区

| 误区 | 正确做法 |
|------|---------|
| 用饼图比较相近的值 | 用柱状图，长度比角度更易分辨 |
| 3D 图表 | 永远使用 2D，3D 会扭曲比例 |
| 双 y 轴 | 分两个子图，或标准化后画在一起 |
| 彩虹配色 | 使用顺序色板或分类色板 |
| 截断 y 轴 | 柱状图 y 轴从 0 开始 |
| 过多类别堆叠 | 合并为"其他"类，最多 5-7 个类别 |

### 色彩方案推荐

| 用途 | 色板类型 | 推荐 |
|------|---------|------|
| 分类（无顺序） | 定性色板 | Tableau 10, Set2 |
| 连续（顺序） | 顺序色板 | Viridis, Plasma, Blues |
| 连续（发散） | 发散色板 | RdBu, coolwarm |
| 色盲友好 | — | Viridis, cividis |
