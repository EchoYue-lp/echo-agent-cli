# Requesting Code Review

When completing tasks, implementing major features, or before merging, request a code review to verify work meets requirements.

## When to Request

- After completing a non-trivial implementation task
- Before merging a feature branch
- When unsure about design decisions
- Before committing significant changes

## Process

1. **Self-review first** — check your own diff for obvious issues
2. **Run all verification** — tests, linting, formatting
3. **Request review** — specify what to look for
4. **Address feedback** — respond to each comment, don't dismiss
5. **Re-verify** — after changes, run tests again
