## 统计方法选择详细指南

### 按数据类型和研究目的选择

| 研究目的 | 数据类型 | 方法 | 前提条件 |
|---------|---------|------|---------|
| 两组均值比较 | 连续，正态 | t 检验 | 正态性、方差齐性 |
| 两组均值比较 | 连续，非正态 | Mann-Whitney U | 独立样本 |
| 配对前后比较 | 连续 | 配对 t 检验 / Wilcoxon | 差值正态性 |
| 多组比较 | 连续，正态 | ANOVA + 事后检验 | 正态性、方差齐性 |
| 多组比较 | 连续，非正态 | Kruskal-Wallis | 独立样本 |
| 分类变量关联 | 分类 × 分类 | 卡方检验 | 期望频数 ≥ 5 |
| 相关分析 | 连续 × 连续 | Pearson / Spearman | 正态/单调 |
| 预测连续值 | 多变量 | 线性回归 | 线性、正态残差、无多重共线性 |
| 预测二分类 | 多变量 | Logistic 回归 | 无多重共线性 |
| 生存分析 | 时间 + 事件 | Kaplan-Meier / Cox | 比例风险 |

### 效应量参考

| 效应量指标 | 小 | 中 | 大 |
|-----------|-----|-----|-----|
| Cohen's d | 0.2 | 0.5 | 0.8 |
| Pearson r | 0.1 | 0.3 | 0.5 |
| Cohen's f (ANOVA) | 0.10 | 0.25 | 0.40 |
| Cramer's V | 0.1 | 0.3 | 0.5 |
| Odds Ratio | 1.5 | 2.5 | 4.3 |

### 多重比较校正

| 方法 | 适用场景 | 特点 |
|------|---------|------|
| **Bonferroni** | 少量比较 | 保守，α/m |
| **Holm-Bonferroni** | 中等数量 | 比 Bonferroni 更有力 |
| **Tukey HSD** | ANOVA 事后 | 控制 FWER |
| **Benjamini-Hochberg** | 大量检验（基因组等） | 控制 FDR |

### 正态性检验方法
- **Shapiro-Wilk** — 小样本首选 (n < 50)
- **Kolmogorov-Smirnov** — 大样本
- **Q-Q 图** — 视觉检查
- **偏度/峰度** — 偏度 |S| < 2 且峰度 |K| < 7 可接受
