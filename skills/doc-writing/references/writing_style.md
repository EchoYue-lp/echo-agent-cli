## 写作风格指南

### 通用原则
- **主动语态** 优先于被动语态
- **短句** 优先于长句（每句不超过 25 个字）
- **具体** 优先于抽象（用数字和例子代替形容词）
- **一段一意** — 每段只讨论一个主题

### 中英文排版规范

| 规则 | 示例 |
|------|------|
| 中英文之间加空格 | `使用 Python 编写` |
| 数字与中文之间加空格 | `共 3 个文件` |
| 全角标点 | `数据：共 3 个。` |
| 专有名词保持原文 | `GitHub`、`Docker`、`API` |

### 标题规范
- 标题不用句号结尾
- 标题层级不超过 4 级
- 同一层级标题格式统一
- 避免孤立标题（标题下没有内容）

### 列表规范
- 并列项语法一致（都用动词开头或都用名词）
- 短项不用句号，长项用句号
- 有序列表表示步骤或优先级
- 无序列表表示并列项

### 表格 vs 列表选择

| 用表格 | 用列表 |
|--------|--------|
| 需要多维度对比 | 单一维度的要点 |
| 数据型信息 | 步骤/流程 |
| 需要精确对齐 | 简短的枚举 |
