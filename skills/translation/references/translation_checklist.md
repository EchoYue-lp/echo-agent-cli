## 翻译质量检查清单

### 准确性检查
- [ ] 所有信息是否完整传达？有无遗漏？
- [ ] 数字、日期、名称是否正确？
- [ ] 否定/肯定方向是否正确？（漏译 not 是最常见的错误之一）
- [ ] 专业术语是否准确？

### 通顺性检查
- [ ] 译文是否读起来像"中文"（或目标语言）？
- [ ] 是否有翻译腔（逐字翻译导致的不自然表达）？
- [ ] 长句是否需要拆分？
- [ ] 主语是否需要调整？（英文多用被动，中文多用主动）

### 一致性检查
- [ ] 术语表中的翻译是否全文统一？
- [ ] 人称和语气是否一致？
- [ ] 格式标记（粗体、斜体、代码块）是否正确保留？

### 常见翻译腔及修正

| 翻译腔 | 问题 | 修正 |
|--------|------|------|
| "这是一个..." | 英文 "This is a..." 的直译 | 直接描述，去掉"这是" |
| "关于...的问题" | "Regarding..." 的直译 | "在...方面" 或直接进入主题 |
| "值得注意的是" | "It is worth noting that..." | "需要注意" 或直接说 |
| "基于..." | "Based on..." | "根据..." 或 "以...为基础" |
| 被动语态过多 | 英文习惯 | 改为主动语态 |
| 过长的定语 | 英文从句直译 | 拆分为短句 |

### 技术文档特殊注意
- 代码块内容**不翻译**（包括变量名、函数名）
- 命令行输出**不翻译**
- API 名称和参数**不翻译**
- 错误信息首次出现时翻译并附原文
