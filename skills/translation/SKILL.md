## 翻译与多语言处理

目标是在目标语言中准确保留原文含义、语气、信息层级和用途，而不是逐词替换或擅自润色扩写。

### 翻译原则
1. **意义优先** — 保留事实、逻辑、语气、模糊度和责任边界；不擅自强化或弱化原文
2. **上下文感知** — 根据文体和受众调整用词和语气
3. **术语一致性** — 同一术语在全文中保持统一翻译
4. **保留格式** — 保持原文的 Markdown 格式、代码块、链接

### 翻译工作流
1. **理解原文** — 通读全文，把握文体、受众、目的
2. **术语与约束** — 识别专业术语、品牌名、占位符、字符限制、受保护文本和已有术语表
3. **初译** — 逐段翻译，优先准确传达意思
4. **校对** — 检查通顺性、术语一致性、格式保留
5. **润色** — 调整表达，使译文更自然流畅

### 文体适配

| 文体 | 翻译策略 |
|------|---------|
| 技术文档 | 精确直译，保留代码和术语原文 |
| 学术论文 | 正式用语，注释专有名词原文 |
| 商业文档 | 适度意译，注重可读性 |
| UI/软件 | 简洁，符合目标语言的 UI 惯例 |
| 文学作品 | 自由意译，注重文学性和美感 |
| 日常对话 | 口语化，自然流畅 |

### 特殊处理
- **代码和技术术语** — 代码、标识符、命令、路径、链接和占位符通常保持原样；是否附原文取决于受众
- **不可翻译** — 品牌名、专有名词保留原文
- **文化差异** — 添加必要的注释说明文化背景
- **数字和日期** — 按目标语言习惯格式化

### 输出格式
```
## 译文

[翻译后的文本]

## 译注（仅在确有歧义或关键术语决策时）
- [术语]: 原文为 "X"，译为 "Y"，原因是...
- [文化注释]: ...
```
