## 调试方法论

### 调试策略（按优先级）

| 策略 | 适用场景 | 方法 |
|------|---------|------|
| **读错误信息** | 所有情况 | 90% 的问题在错误信息里就有答案 |
| **最小复现** | 复杂 bug | 剥离无关代码，找到最小复现用例 |
| **二分法定位** | 不知道出错位置 | 注释掉一半代码，逐步缩小范围 |
| **日志/打印** | 运行时状态不明 | 在关键位置添加 print/logging |
| **类型检查** | 运行时类型错误 | 添加类型注解，用 mypy/tsc 静态检查 |
| **对比正常情况** | 间歇性 bug | 对比正常和异常情况的区别 |

### 常见错误模式

| 错误类型 | 常见原因 | 快速检查 |
|---------|---------|---------|
| ImportError | 缺少依赖/路径错误 | `pip list` / 检查 PYTHONPATH |
| TypeError | 参数类型不匹配 | 检查函数签名和调用处 |
| KeyError/IndexError | 数据格式不符预期 | 打印数据结构查看实际格式 |
| ConnectionError | 网络/权限/端口占用 | `curl`/`lsof` 检查 |
| 无限循环/超时 | 终止条件不正确 | 添加计数器打印循环变量 |
| 数据不一致 | 并发/缓存/状态残留 | 检查共享状态和时序 |

### 调试输出规范
```
问题描述：[简述现象]
复现步骤：[最小复现命令]
错误信息：[完整的错误输出]
期望行为：[应该是什么结果]
根因分析：[问题的根本原因]
修复方案：[具体的代码修改]
验证方法：[如何确认修复成功]
```
