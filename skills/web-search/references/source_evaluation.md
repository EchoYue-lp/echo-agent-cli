## 来源可信度评估指南

### 可信度分级

| 等级 | 来源类型 | 示例 |
|------|---------|------|
| **A 级（高可信）** | 政府官网、学术机构、国际组织 | .gov、.edu、WHO、UN |
| **B 级（较可信）** | 权威媒体、专业期刊、行业报告 | 新华社、Nature、Gartner |
| **C 级（需验证）** | 科技媒体、专业博客、企业官网 | TechCrunch、公司博客 |
| **D 级（低可信）** | 论坛、社交媒体、个人网站 | Reddit、知乎、微博 |

### 评估维度
1. **权威性** — 作者/机构的专业资质和声誉
2. **时效性** — 发布/更新时间，信息是否仍然有效
3. **客观性** — 是否有明显的利益冲突或偏见
4. **准确性** — 是否引用了数据和来源，是否可交叉验证
5. **完整性** — 是否全面呈现了多方观点

### 红旗信号（需警惕）
- 标题党、过度情绪化的表述
- 无署名、无日期、无来源引用
- 数据与已知事实严重矛盾且无解释
- 明显的商业推广或政治宣传意图
