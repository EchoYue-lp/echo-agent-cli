## PRISMA 报告清单

PRISMA (Preferred Reporting Items for Systematic Reviews and Meta-Analyses) 是系统综述的报告规范。

### 报告流程

```
识别 (Identification)
├── 数据库检索获得记录数: n
├── 其他途径获得记录数: n
└── 去重后记录数: n

筛选 (Screening)
├── 标题和摘要筛选: n
├── 排除记录: n (标注原因)
└── 全文评估: n

纳入 (Included)
├── 定性合成: n 篇
└── 定量合成 (Meta分析): n 篇
```

### 必要报告项目（精简版）

| 部分 | 必报内容 |
|------|---------|
| **标题** | 明确标注"系统综述"或"Meta分析" |
| **摘要** | 结构化：背景、方法、结果、结论 |
| **引言** | 研究目的、PICO 问题 |
| **方法** | 检索策略、纳入/排除标准、数据提取、质量评估方法 |
| **结果** | PRISMA 流程图、研究特征表、质量评估结果、主要发现 |
| **讨论** | 证据总结、局限性、对实践和研究的启示 |
| **资金** | 资金来源和利益冲突声明 |

### 检索策略记录模板
```
数据库: PubMed
检索日期: YYYY-MM-DD
检索式:
#1 "orthopedic nursing"[MeSH] OR "orthopaedic nursing"
#2 "postoperative care"[MeSH] OR "perioperative"
#3 #1 AND #2
筛选: 日期 2010-2024, 英文/中文, 人类研究
结果: n 篇
```
