# Eko Branding Draft

Recommended short name: **Eko**

Rationale:
- 3 letters, easy to say, and close enough to Echo to keep brand continuity.
- Feels like a modern coding/cowork tool name beside Codex, Cursor, and OpenClaw.
- Works as a compact app label in the sidebar, menu bar, and terminal output.

Icon concept:
- A calm geometric orbit suggests long-running autonomous work.
- The three strokes form a clear `E` without drawing a literal wordmark.
- The right node suggests an active agent handoff point.
- Teal/green is used sparingly as the running/accent state.

Files:
- `eko-icon.svg`: dark app icon draft.
- `eko-icon-light.svg`: light app icon draft.
- `eko-mark.svg`: monochrome mark for UI and small inline usage.
